# Certification Conversation to Markdown

An agent skill for turning Microsoft Learn certification pages or supplied HTML into a structured Markdown study repository.

The skill:

- follows certification training paths, modules, and lesson units;
- preserves instructional explanations, code, diagrams, and useful links;
- excludes exercises, labs, assessments, videos, and site navigation; and
- validates coverage while clearly reporting unavailable source material.

## Usage

Provide the agent with a Microsoft Learn certification URL, saved HTML, or pasted HTML and ask it to create Markdown study notes. See the [skill definition](./converting%20certification-content-to-markdown/SKILL.md) for the complete workflow and output structure.
