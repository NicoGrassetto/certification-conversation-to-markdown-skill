# Contributing

Contributions are welcome.

1. Open an issue before making a substantial change.
2. Keep each change focused and consistent with the [skill definition](./converting%20certification-content-to-markdown/SKILL.md).
3. Update related documentation when behavior changes.
4. Run `git diff --check` and review the rendered Markdown.
5. Open a pull request describing the change and how it was validated.

By contributing, you agree that your contribution will be licensed under the repository's [MIT License](./LICENSE).
