# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the default branch. Older commits and copies of the skill are not supported.

## Reporting a Vulnerability

Do not report vulnerabilities in a public issue. Use GitHub's [private vulnerability reporting](https://github.com/NicoGrassetto/certification-conversation-to-markdown-skill/security/advisories/new) when available. Otherwise, contact the repository owner privately through the contact information on their [GitHub profile](https://github.com/NicoGrassetto).

Include the affected content, potential impact, reproduction steps, and any suggested mitigation. The maintainer will investigate the report and coordinate disclosure and remediation as appropriate.
